⑤ 按钮体系统一 + 微动效

现状主按钮是「拟物厚底」（4px 底边 + 按压位移），而 ghost / seat-chip / mode-card 是「平面描边」——两套语言同屏。建议统一为一套：实心主按钮用轻投影表达可按，次按钮纯描边；同时给弹窗加 180ms 出现动画（现在是 display 硬切）：

⑥ 远期方向：夜间主题

牌局常在晚上打，纯白桌面刺眼。design-preview 里已有的「方案C · 夜牌」稿（深底 + 亮绿 + 高对比数字）方向是对的。落地成本低：所有颜色已走 CSS 变量，补一套 [data-theme=dark] 变量值即可，建议放到 token 收敛之后再做。
