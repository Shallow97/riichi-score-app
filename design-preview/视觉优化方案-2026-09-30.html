前端视觉优化方案

日麻计分 APP（prototype / 393px 窄屏） · impeccable 审查驱动 · 2026-09-30 · 仅方案，未动任何代码

设计上下文（沿用已批准口径）

使用者：面对面打日麻的牌友，房主手机计分、局域网多人看同一界面。核心诉求是「扫一眼看清谁多少分、下一手点哪」。视觉基调沿用 2026-09-28 已批准的外观体系（品牌绿 + 圆角 10/14/20 三档 + 阴影两档 + 字重 ≤700），本轮只做收敛与修补，不推翻方向。

审查结论

做得好的（保持不动）
  • 信息层级正确：座位卡分数 22px 等宽数字是第一焦点，局号已收敛到 16px；东风位即庄家的约定清晰。
  • 对比度工作已做过一轮：text-dim / gold / danger-text 都换成达标色并写明比值。
  • 有品牌意象：立直棒（白条红点）贯穿桌面、选人、逐局记录，不是泛 AI 界面。
  • 动效克制：弹窗 120ms 减晃版 + 链内 .instant，符合工具类定位。
问题（按严重度）
  • [P1] 0 分着色 .pts.neg2 仍是废弃旧金 #C9992E（白底 2.60:1，连大字 3:1 都不达标；token 早已换成 #8F6B12）。
  • [P1] 桌面四角按钮三种视觉语言混用：⚄ Unicode 字符（部分 WebView 渲染成彩色 emoji，不可控）、汉字「算」「？」、线性 SVG（视角）。同一桌面图标不成体系。
  • [P1] 主界面顶栏「‹ 返回」「新对局」是 14px 文字 span，触控热区远小于 44px，是全屏唯一不达标的可点元素。
  • [P2] 硬编码色残留约 15 处（风牌四色、notice、取景框、骰面、toast、var(--card,·) 引用了不存在的 token）。浅色下无症状，但是夜间主题的直接障碍。
  • [P2] 「本局操作」六个按钮同权重：最高频的「和牌结算」与低频破坏性的「结束对局」视觉完全同权，主操作 2 秒内认不出来。
  • [P2] 空状态只有一行灰字（历史页、半庄分数记录），没有引导。
  • [P3] 座位卡「你」角标 9px、meta 10px，偏小。

改进项（逐项确认）

A · P1一致性修复：0 分旧金色 + 失效 token

改法　.pts.neg2 由 #C9992E 改为 var(--gold)；.eink-scan-item 的 var(--card, #fff) 改为 var(--surface)。

改动：仅 css/style.css 两行，零 DOM 风险。　验证：全量 jsdom 测试 + 截图对比。
B · P1桌面四角按钮图标语言统一

改法　骰子 ⚄ 与「算」改为与视角按钮同一笔画的线性 SVG（24×24、stroke-width 2）；右上「？」保留不动（字形位移是滑块校准过的，动它要重新校准，收益为零）。

风险说明：改的是 index.html 按钮内部内容，按钮 id 不变；已核对全部测试均按 id 断言存在/点击，不锁这两个按钮的文字。

改动：index.html 两处内容 + style.css 微调。　验证：全量测试 + CDP 真浏览器 393×852 截图。
C · P1顶栏触控热区补到 44px

改法　.topbar .back（含 #btn-new-game）加纵向 padding 12px + 负 margin 抵消，热区到 44px，视觉位置不变。

改动：仅 style.css。　验证：CDP 量取 getBoundingClientRect ≥44px。
D · P1硬编码色收进 token（夜间主题前置工程）

改法　把风牌四色、notice 双色、scan-frame 绿、骰面墨色、toast 底色等约 15 处硬编码值原样搬进 :root token，值一律不变，只挪位置。夜间主题是已批方向，这步做完它才有可能。

改动：仅 style.css。　验证：全量测试 + 截图比对像素级应无变化。
E · P2观感变化最大，请拍板操作按钮分主次

改法　「和牌结算」升为主按钮（品牌绿实心）；「结束对局」降为幽灵描边 + 深红文字；其余保持白底描边。纯 CSS 按 id 定制，不改 class 名。

改动：仅 style.css。　验证：全量测试（view-lock-test 读过 style.css，改后必须跑）+ 截图。
F · P2空状态引导

改法　历史页与「半庄分数记录」空态：灰字上方加一枚小型立直棒图形（复用现有白条红点意象，纯 CSS 绘制），文案微调为引导句（如「完成第一局结算后，记录会显示在这里」）。

改动：index.html 空态节点 + style.css + app.js 空态文案处。DOM 有增节点，改后全量跑测试确认。
G · P3小字可读性微调

改法　座位卡「你」角标 9px→11px、meta 10px→10.5px，不破 108px 卡宽布局。

改动：仅 style.css。　验证：真机截图确认不溢出。
H · P3建议本轮不做
  • 内嵌数字字体：体积与离线打包成本高，系统字体在小米 14 渲染尚可，不建议。
  • 夜间主题：方向已批，但属独立立项，建议 D 项完成后再单独出方案。
