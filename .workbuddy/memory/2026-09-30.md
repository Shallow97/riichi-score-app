## APP 内集成蓝牙推送的可行性结论（2026-09-30）
- **Web Bluetooth 在 WebView 里永不可用**：WebView 即 Chromium，但 Google 明确不实现（官方 web.dev《Web on Android》：有 OS 级替代的 API 不进 WebView），无 flag 可开；嵌完整 Chromium（+50MB）不划算 → "换内核"路线否决
- **Custom Tabs 能用 Web BLE（真 Chrome 进程）但体验有硬伤**：Custom Tab 全屏盖在 APP 上，用户必须关掉它才能操作计分界面；关掉即页面销毁 → 自动推送中断。折衷：ACTION_VIEW 跳真 Chrome，用户切回 APP 后 Chrome 后台 tab 继续 WS+BLE 推送（需手机装 Chrome）
- **推荐正解 = 原生 BLE 桥（不依赖 Web Bluetooth）**：服务器本来就在 APP 进程内（RiichiServer），游戏状态广播时直接调原生 BLE 客户端推送；渲染走服务端 Canvas（与 COOIOT /display 方案同款）；tagpush.js 的 EPD-nRF5 协议用 Java 重写（BluetoothGatt 分块写 + 通知订阅，约 400-500 行）+ BLUETOOTH_SCAN/CONNECT 运行时权限（Android 12+，用户机 Android14 OK）。tag.html 保留作 Chrome 备用通道

## 局部刷新可行性结论（2026-09-30，查固件源码）
- **BLE 协议不暴露局部刷新**：EPD_service.c 命令集=SET_PINS/INIT/CLEAR/SEND_COMMAND/SEND_DATA/REFRESH/SLEEP/SET_TIME/WRITE_IMAGE/SET_CONFIG/SYS_SLEEP/SYS_RESET/CFG_ERASE；REFRESH 恒走 drv->refresh()=全屏 LUT 刷（BWR 约15s闪刷）；WRITE_IMG 的 write_ram 路径固定全屏窗口（UC81xx.c:251 SetWindow(0,0,W,H)）
- UC81xx 控制器硬件支持 partial window（0x90/0x91/0x92），固件内部 UC8176_WriteImage 也用了 PTIN/PTOUT——但那走 write_image 路径，BLE 推图用不到
- docs/README.md 原话：三色屏换 BW LUT 可 15s→2-3s；"theoretically, a LUT supporting partial refresh could also be created"（连作者都未实现三色局部刷新 LUT）
- 协议留有原始透传口子（SEND_COMMAND/SEND_DATA 直写 SPI，EPD_service.c:174-181），理论上可自写 partial 流程，但固件不管 busy、无 LUT 库，不值
- epd-noclock 本地只有 README+index.html（无固件源码），其网页功能亦无 partial
- **对场风盘影响：无**。本来设计=每局结算刷一次，10s 节流+15s 全刷在体验预算内；想快只能牺牲红色换 BW LUT（2-3s），与三色需求冲突

## 黑白快刷模式实现（2026-09-30，提交 04d373e，用户定：优先低延时）
- **方案**：INIT 带 model=0x01(UC8176_420_BW，固件按黑白初始化 PSR 0x1F/CDI 0x97) → SEND_CMD(0x03)/SEND_DATA(0x04) 透传写 PSR 0x3F(=0x1F|0x20 LUT_SEL=寄存器)/CDI 0x97 + bw.txt 五张 LUT（0x20-0x24，同寄存器连续 SEND_DATA 分块续写）→ 单张黑白面（红像素灰度~106-120<140 自然落黑）→ REFRESH；关闭=INIT 带 model 0x03 三色全刷（INIT 硬重置会清掉寄存器 LUT，无需恢复现场）
- **⚠️ 每次推送都重走 INIT+寄存器**（深睡重置寄存器 + 模式切换即时生效）
- **顺手修 Java 真 bug**：旧式非压缩标志 0x0F/0xFF/0x00/0xF0 的 bit2=1 会被新版固件误判为 RLE（固件解析 bit0=黑红/bit1=首块/bit2=RLE，EPD_service.c:216）→ 改为黑面 0x02/0x00、红面 0x03/0x01；tagpush.js 走 RLE 路径不受影响（固件恒报 rle=1，EPD_service.c:128）
- **渲染 BW 变体**：庄家"东"=反白块（黑底白字，drawWind/render 双端一致）；负分/场供/立直点转黑；tag.html 快刷开关 localStorage(tag_bw)+?bw=0/1；APP 控制页 switch-eink-fast → NativeBridge.einkSetFastMode/einkIsFastMode（SharedPreferences "eink/fast" 默认 true）
- **验证**：CDP 截图两模式（05-tag-bw.png red=0% / 06-tag-color.png red=0.117%）；21 个 jsdom 测试绿；gradle 打包中
- **⚠️ 实机待验证**：PSR_BW=0x3F 的 bit5(LUT_SEL) 语义按 UC81xx 系列数据手册推定，快刷不生效或花屏先改这一个字节（0x3F↔0x1F），无损可回退（开关切回三色即可）
