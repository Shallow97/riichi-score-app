### 2. 网络诊断（本轮最费时，也最有复用价值）
| 路径 | `github.com` | `api.github.com` |
|---|---|---|
| 沙箱内直连 | 超时 | 通 |
| 沙箱内经沙箱代理 60185 | **CONNECT 502**（白名单未含 github.com） | 200 / 401 |
| 沙箱内经 Clash `127.0.0.1:7897` | **200**（0.5s） | 通 |
| 沙箱外直连 | **时通时断**（1.0s 成功 → 21s 超时，多 IP 轮询部分线路不可达） | 200 |

**结论：git 对 github.com 一律走 Clash 7897**——它在沙箱内外都可用（127.0.0.1 是回环，且 Clash 是用户进程、出网不受沙箱代理限制）。
