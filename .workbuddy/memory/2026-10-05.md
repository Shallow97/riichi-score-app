## 首页新增「推送二维码到场风盘」按钮

**需求（用户先提问确认，4 项）**
1. 二维码内容 = 卡片里那个「加入本桌」链接 `http://<房主IP>:8765/`
2. 位置 = 「联网对局」卡片内（不是和「场风盘蓝牙控制」并列）
3. 没有可推二维码（成员身份 / 未联网）时 **隐藏按钮**（不是置灰）
4. 推送后被立直/结算的自动推送覆盖 → 可接受

**改动**
- `prototype/index.html`：`#net-room-qr` 内加 `<button id="btn-push-qr" disabled>📡 推送二维码到场风盘</button>`（放在 `#qr-url` 之后）→ 无二维码时随卡片一起 `display:none`，天然满足需求 3
- `prototype/js/app.js`
  - 新增 `currentJoinUrl` / `einkConnected` 状态；`updateNetStatusUI` 各分支维护 `currentJoinUrl`
  - 新增 `syncPushQrBtn()` / `refreshEinkConnected()` / `buildQrPngBase64(text)` / `onPushQrClick()`
  - `EinkNative.onStatus`：`connected`→可点；`disconnected`/`connecting`/`connect-fail`/`connect-giveup`→置灰
  - `showPage('page-mode')` 与 `init()` 末尾调 `refreshEinkConnected()`
  - `buildQrPngBase64`：qrcode.js（自动扩容、EC M）→ 按模块整数倍 `fillRect` 画进 400×300 白底画布（静默区 4 模块）→ `toDataURL('image/png')` 去前缀
