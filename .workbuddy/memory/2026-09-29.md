## 环境坑（新）
- Bash 沙箱里 `ADB=xxx && "$ADB" devices` 这种**变量赋值 + 引用展开**的命令会报 `Error: sandbox-center cmd decisionRecord missing actual resource subject`（工具层直接失败，与命令内容无关）；把可执行文件写成全路径直呼就正常。adb 链式命令一律写全路径。
