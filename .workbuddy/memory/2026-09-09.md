## 房主初始页新增"扫码加入本桌"二维码
- 需求：房主模式选择(初始)页增加二维码，其他玩家扫码即可打开链接加入，省去手动输 IP:端口。
- 交付口径（用户选定）：仅房主联网建局时显示，放在"联网对局"卡片内的 `#net-room` 区域。
- 二维码内容 = `http://<本机IP>:<port>/`（不带 `host=1`，扫码加入即成员）；IP 复用现有三级回退（?lanip= → window.__LAN_IP__ → location.hostname），端口跟随 `location.port || 8765`。
- 二维码库：采用 `qrcode-generator` v1.4.4（Kazuhiko Arase, MIT，纯 JS 离线可用，无需网络/CDN，适合 Android WebView）。文件放 `prototype/js/qrcode.js` 与 `android/.../assets/js/qrcode.js`。
- 关键 API 坑：该库 `createDataURL` 用的是**内置 GIF 编码器**，返回 `data:image/gif;base64,...`（**不是 PNG**），纯 JS 无 canvas 依赖，浏览器/WebView 的 `<img>` 与手机相机扫码均正常。
- 改动文件（prototype 与 android assets 三件套须保持一致）：
  - index.html：`#net-room` 内加 `<div id="net-room-qr">`(内含 `#qr-canvas` + `#qr-url`)，并在 `<script src=js/app.js>` 前插 `<script src=js/qrcode.js>`。
  - css/style.css：新增 `.net-room-qr/.qr-title/.qr-canvas/.qr-url` 样式（白底圆角、链接可换行）。
  - js/app.js：`updateNetStatusUI` 房主分支算 hostIp/port/fullUrl → 写 `#qr-url` 并调 `renderQR`；新增模块级 `renderQR(block, canvas, text)`（typeNumber 0 自动扩容 / 纠错 M，输出 160px img；链接不变则跳过重绘防闪烁）。成员/离线分支隐藏 `#net-room-qr`。
- 踩坑（易复发）：renderQR 必须把图片写进**里层 `#qr-canvas`**、外层 `#net-room-qr` 只控显隐，切不可对 `#net-room-qr` 整块 `innerHTML=''`——会把同级 `#qr-url` 一起抹掉。原实现把 img 直接塞外层导致 qr-url/qr-canvas 被清空。
- 测试：新增 `prototype/tests/qrcode-host-test.js`（13 断言：全局 qrcode 函数存在/GIF data URL 可生成/房主显示与链接正确/成员与离线隐藏）。全量离线回归通过（domtest 210、view-lock 60、score-calc 45、tsumo3-honba 38、operator-release 9 等）。net-test.js 需联网服务器故未跑。
