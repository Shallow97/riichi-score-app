## 联网同步（协议 v2）
- 单房间；房主 = WS `?host=1`；全员平权申请操作权；流局/修正/撤回/结束仅房主
- **全提交制**：`commit{opId,baseSeq,state}` 上行 → 服务器校验 `seq`+`opId` 幂等 → 回 `ack` 才落库；其余端收 `state{state,seq}`（跳过提交者）
- `welcome{role,state,seq,operator,hostOnline,hostSeen}` 全量下发；`conflict{reason:stale|denied}` 采用带回的权威态
- **设备数只在房主端可见**（成员端 `Net.memberCount()` 恒 1）
- **用户名**：`riichi_profile.name` 只由显式动作写（`#btn-set-name`/`lockView()`），⚠️ **建局绝不写它**；每次 onopen 补报 `set-name`（否则重连后退化成"暂时无法操作"）
- 心跳：服务器 20s / 客户端 10s ping；客户端 40s 无消息重连；服务器 75s 无消息判死链
- ⚠️ **操作权租约 `OP_LEASE_MS=45000`**：45s 无**任何上行消息**才清 `room.operator`（只释放槽位、不 close）。**故意不做「页面隐藏即释放」**；`serve.js` 可 `RIICHI_OP_LEASE_MS` 覆盖
- ⚠️ 已知瑕疵（未修）：被回收后本地 `iAmOperator` 仍 true，UI 短暂显示"你正在操作"；数据不会错
- ⚠️ **看门狗两条豁免**：房主连接豁免；页面隐藏期间不判死 + `installVisibilityProbe()` 回前台主动 ping —— **静默 ≠ 断链**
- `webView.onPause()` 已移除但**不是降频元凶**（真因 Chromium 后台节流）；已 `setRendererPriorityPolicy(RENDERER_PRIORITY_IMPORTANT,false)`
- 房主断链 → 保留房间 + `host-offline`，重连 `host-online`；只服务器本体死才散桌。`Net.isLocked()`=`hasJoined && !connected`
- ⚠️ 提交一律显式 `Net.commit`（`Storage.hooks.onSave` 不再安装）；⚠️ **申请操作权应答必须与 `operator-change` 广播分离**（`actionReq{cb,timer}`，只有 `action-granted/denied` 结算）
- ⚠️ **Java 连接生命周期必须互斥**（`roomLock` 包住 onConnected/onDisconnected，`prev.close()` 挪到锁外；锁序只允许 `roomLock → this`）
- **批次 1–4 已完成**（重连/心跳/僵尸连接；看门狗豁免；锁屏保活；操作权租约）→ 见 `2026-10-03.md`，勿重复排查

## 工具链（要点 + 坑）
- 构建：`export JAVA_HOME=D:/tools/jdk-17.0.2`、`export GRADLE_USER_HOME=D:/tools/gradle-home`；`android/` 下 `D:/tools/gradle-8.2/bin/gradle.bat clean assembleDebug --no-daemon` → cp 到根 `日麻计分APP-debug.apk`（SDK 走 `local.properties` 的 `sdk.dir`）
- adb 绝对路径；包名 `com.riichi.score`。验证链：`install -r` → `dumpsys package|grep lastUpdateTime` → `monkey … LAUNCHER 1`+`pidof` → CDP 查 DOM
- ⚠️ Bash 里 `ADB=xxx && "$ADB" …` 会报 `sandbox-center cmd decisionRecord` → **写全路径直呼**；⚠️ 并行两条 adb 互抢 server → 串行写同一条 Bash
- 测试：`cd prototype/tests && NODE_PATH="C:/Users/Administrator/.workbuddy/binaries/node/workspace/node_modules" "<node.exe>" <脚本>.js`。⚠️ `net-test.js` **需先起 `serve.js`**（8765），否则 ECONNREFUSED；⚠️ 与"8765 被占"互相冲突，别同时跑
- **真机 CDP**：`grep -o "@webview_devtools_remote_[0-9]*" /proc/net/unix` → `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>`（**不带 @**）→ node+`ws` 发 `Runtime.evaluate`。⚠️ socket/forward/CDP 写同一条 Bash。⚠️ WebView 内 `input tap` 不可靠（改 CDP 注入）；原生对话框才用 tap
- `tools/cdp-eval.js <表达式文件> [9222真机|9333真Chrome]`；⚠️ 表达式走**文件路径**传参
- 真浏览器：`cd prototype && node serve.js`（后台任务方式）→ `chrome --headless=new --remote-debugging-port=9333 --user-data-dir=D:/_cdp_* --window-size=393,900 "<url>"`；⚠️ headless 最小 512px → 需 CDP `Emulation.setDeviceMetricsOverride` 才能按 393 截；⚠️ Node 22 自带全局 `WebSocket`（写 CDP 脚本可不 require ws）；⚠️ 页面 `url` 是 `http://127.0.0.1:8765/?host=1…`，**不含 index.html**（按 url 找 target 别写错）
- 截单机 UI 别起 serve.js → `file:///…/prototype/index.html`；⚠️ curl 必须 `--noproxy '*'`；Git Bash 不可写 `/tmp`、`/dev/null` → 输出写 `D:/`
- 其它：`tools/e2e-host-lock-watch.js <ws://IP:8765/ws> <分钟>`（锁屏保活回归，**PC 上跑且别碰手机**）
- ⚠️ 判断"页面到底连没连"看 **`/proc/net/tcp6` 有无 8765 已建立连接**（`grep 223D`）；⚠️ `#toast` 是 fixed、`offsetParent` 恒 null → 用 `getComputedStyle`；验证前先关残留弹窗
